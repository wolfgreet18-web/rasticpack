# کپی سریع

یک اپ خیلی ساده اندروید برای کپی سریع یک متن از صفحه اصلی گوشی.

## کارکرد
1. برنامه را باز کن و متن/شماره کارت را وارد کن.
2. روی «کپی متن» بزن تا ذخیره و کپی شود.
3. روی صفحه اصلی گوشی نگه دار → ویجت‌ها → «کپی سریع».
4. ویجت را روی صفحه بگذار.
5. هر بار روی ویجت بزنی، همان متن داخل کلیپ‌بورد کپی می‌شود و هرجا خواستی Paste می‌کنی.

## ساخت APK با GitHub
پوشه را به یک repository عمومی GitHub آپلود کن. فایل workflow داخل `.github/workflows/build.yml` به‌صورت خودکار APK را می‌سازد.
