# کپی سریع Pro 2.0

نسخه حرفه‌ای‌تر: چند متن، چند ویجت مستقل، انتخاب متن هنگام ساخت هر ویجت، کپی با یک لمس، ذخیره محلی و بدون اینترنت.

## ساخت APK با GitHub
1. کل پوشه پروژه را در یک repository عمومی GitHub آپلود کن.
2. Actions را باز کن.
3. workflow با نام Build APK را اجرا کن.
4. بعد از سبز شدن، از Artifacts فایل APK را دانلود کن.

## استفاده
1. برنامه را باز کن و مثلاً «کارت بانک» + شماره کارت را ذخیره کن.
2. روی صفحه اصلی گوشی: نگه‌داشتن روی صفحه → Widgets → کپی سریع.
3. هنگام افزودن ویجت، متن موردنظر را انتخاب کن.
4. برای هر متن یک ویجت جدا بساز.
