# رستیک پک — نسخه اندروید (مرحله ۱: پروژه پایه)

این پوشه یک پروژه‌ی خالیِ Android (Kotlin + Jetpack Compose) است. تنها کاری که این نسخه
می‌کند این است که باز شود و یک صفحه‌ی «خوش‌آمد» با رنگ و لوگوی برند رستیک پک نشان دهد.
هدف این مرحله فقط این است که مطمئن شویم مسیر **گیت‌هاب ← ساخت خودکار (Build) ← نصب روی گوشی**
درست کار می‌کند — قبل از اینکه منطق پیچیده‌تر (دیتابیس، محاسبات، تب‌ها) اضافه شود.

## چطور APK را بسازم و روی گوشی نصب کنم؟ (بدون کامپیوتر یا Android Studio)

1. یک مخزن (repository) تازه در گیت‌هاب بسازید و تمام فایل‌های این پوشه را در آن آپلود کنید
   (می‌توانید از طریق سایت گیت‌هاب فایل‌ها را درگ-اند-دراپ کنید، یا این پوشه را زیپ کرده و
   از گزینه‌ی «Upload files» استفاده کنید — نکته: پوشه‌ی `.github` هم باید حتماً آپلود شود،
   چون فایل ساخت خودکار همان‌جاست).
2. بعد از آپلود، به تب **Actions** مخزن بروید. یک اجرا (run) به اسم «ساخت APK» خودش شروع
   می‌شود (چون فایل build.yml تنظیم شده که با هر push اجرا شود). اگر شروع نشد، دستی روی
   دکمه‌ی **Run workflow** بزنید.
3. صبر کنید تا اجرا سبز (✅) شود — حدود ۲ تا ۴ دقیقه طول می‌کشد.
4. روی همان اجرا کلیک کنید؛ در پایین صفحه بخش **Artifacts** یک فایل به اسم
   `rasticpack-debug-apk` می‌بینید. آن را دانلود کنید — یک فایل zip است که داخلش
   فایل APK قرار دارد.
5. فایل APK را به گوشی اندرویدی خودتان منتقل کنید (مثلاً از طریق تلگرام به خودتان، یا
   دانلود مستقیم از گوشی روی همان صفحه‌ی گیت‌هاب) و نصبش کنید. اندروید ممکن است هشدار
   بدهد «از منبع ناشناس» — این طبیعی است، چون اپ از گوگل‌پلی نیامده؛ اجازه‌ی نصب را بدهید.

## چیزهایی که در این مرحله *نیستند* (در مراحل بعد اضافه می‌شوند)

- موتور محاسبه چیدمان/پرت روی ورق (معادل تب «قیمت»)
- دیتابیس برای فاکتور، مشتری، موجودی ورق
- تب‌های فاکتورها، مشتری‌ها، موجودی، تولید، آمار، تنظیمات/بکاپ
- فونت فارسی وزیرمتن (فعلاً فونت پیش‌فرض سیستم استفاده می‌شود — فارسی را درست نشان
  می‌دهد، فقط ظاهرش با نسخه‌ی وب یکی نیست)

## ساختار پوشه‌ها

```
RasticPack/
├── app/
│   ├── build.gradle.kts                 ← کتابخونه‌ها و تنظیمات ماژول اپ
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/rasticpack/app/
│       │   ├── MainActivity.kt          ← نقطه ورود + صفحه خوش‌آمد
│       │   └── ui/theme/                ← رنگ‌ها (Color.kt)، تم (Theme.kt)، فونت (Type.kt)
│       └── res/
│           ├── values/                  ← رنگ آیکون، متن‌ها، تم پایه
│           ├── drawable/                ← لوگوی سه‌فلش (ic_launcher_foreground)
│           ├── mipmap-*/                ← آیکون اپ برای نسخه‌های مختلف اندروید
│           └── xml/                     ← قوانین بکاپ/استخراج داده
├── .github/workflows/build.yml          ← ساخت خودکار APK با هر push
├── build.gradle.kts / settings.gradle.kts / gradle.properties
└── .gitignore
```

## اگر روی کامپیوتر خودتان با Android Studio باز کنید

فقط پوشه‌ی `RasticPack` را در Android Studio باز کنید («Open» → انتخاب این پوشه).
گرادل به‌صورت خودکار (`gradlew` را خودش می‌سازد چون Android Studio از قبل Gradle نصب دارد)
همه چیز را sync می‌کند و می‌توانید مستقیم روی گوشی متصل یا شبیه‌ساز اجرا کنید.
